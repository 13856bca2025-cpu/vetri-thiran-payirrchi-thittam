# FitBuddy – AI Fitness Plan Generator

FitBuddy is a complete AI-assisted fitness planning application built with:

- FastAPI
- Jinja2
- SQLAlchemy
- SQLite
- Pydantic
- Google Gemini
- HTML/CSS
- Pytest

## Features

- Personalized 7-day workout plan generation
- Goal-aware planning
- Intensity-aware planning
- Nutrition/recovery tip
- Feedback-based workout revision
- SQLite persistence
- Admin dashboard
- REST API
- Swagger API documentation
- Demo mode
- Gemini integration
- Automated tests
